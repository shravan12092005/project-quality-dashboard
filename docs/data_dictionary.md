## KPI Definitions

| KPI | Formula | Scope |
|----|---------|-------|
| Total Defects | COUNT of Defects rows | All statuses |
| Open Defects | COUNT where Status IN (Open, In Progress, Re-Opened) | Excludes Deferred |
| Closed Defects | COUNT where Status = Closed | — |
| Deferred Defects | COUNT where Status = Deferred | Tracked separately |
| Closure Rate % | Closed / Total × 100 | — |
| Avg Resolution Days | AVG(Resolution_Days) for Closed defects only | — |
| SLA Compliance % | SLA_Met=TRUE / Closed × 100 | Closed defects only |
| Cumulative Backlog | Running total: Created − Closed up to date | Time-series |
| Open Action Items | Issues where Type=Action Item, Status≠Closed | — |
| Overdue Action Items | Issues where Type=Action Item, Is_Overdue=TRUE | — |
| Avg Risk Score | AVG(Risk_Score) for Open/Escalated risks | — |
| High Risks | COUNT where Risk_Score≥15 AND Status Open/Escalated | — |
| Review Completion % | Completed reviews / Total reviews × 100 | — |
| Overdue Reviews | COUNT where Is_Overdue=TRUE | — |
| Audit Findings Open | Issues where Type=Audit Finding, Status≠Closed | — |
